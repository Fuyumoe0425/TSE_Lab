A simple Streamlit app template for you to modify!

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://blank-app-template.streamlit.app/)

## Agent Coordination

This project uses multiple agents for development. For information about agent activities and coordination:

- See [AGENT_COORDINATION.md](AGENT_COORDINATION.md) for coordination information and FAQ
- See [docs/AGENT_ACTIVITIES.md](docs/AGENT_ACTIVITIES.md) for detailed activity logs

### How to run it on your own machine

1. Install the requirements

   ```
   $ pip install -r requirements.txt
   ```

2. Run the app

   ```
   $ streamlit run streamlit_app.py
   ```
